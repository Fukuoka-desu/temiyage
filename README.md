# 手土産えらび

全国941品から、贈る相手の出身地・好み・予算・用途に合う手土産を選ぶ静的Webアプリです。Vite + React + TypeScript、システムフォントとローカルデータのみで動きます。

## 使い方

条件パネルで土地・好み・予算・シーンを選ぶと候補が更新されます。好みは複数選択でき、いずれかに合う品が候補になります。産地・ジャンル・キーワードでさらに絞り込み、並べ替えができます。最初は24件表示し、「もっと見る」で24件ずつ追加します。スマートフォンでは条件を折りたたみ、「候補を見る」で結果へ移動できます。

「この条件を共有」で、全条件を含んだURLをコピーします。クリップボードが使えない環境ではURL欄から手動でコピーできます。「条件をリセット」で初期条件へ戻せます。

おすすめ順は確認済みの品を先に並べ、その中で条件のスコアが高い順、同点では価格の安い順です。他の並べ替えでは確認状況に関係なく指定した順になります。価格不明は候補から除外。日持ち不明は「日持ち重視」でも含み、日持ち順では末尾に表示します。価格帯の近傍（下限の80%〜上限の115%）の品も候補に含みます。

## 開発・検証

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run preview
```

`dist/` に静的ファイルが生成されます。Viteのbaseは `./` で、サブディレクトリにも配置できます。ビルド成果物・node_modulesはコミット対象外です。実行時の外部通信は商品リンクのクリックのみで、ログイン・個人情報の入力・アクセス解析・外部フォント・外部CDNはありません。

## データの出典と更新

唯一の元データは `/workspace/temiyage/temiyage_master.csv` です。941品、47都道府県、2026年10月28日のWeb調査。850品はメーカー公式・公式通販・百貨店で税込価格の一致を確認し、91品は要確認です。価格未記載は53品、日持ち未記載は389品です。各カードに元データの出典リンク・種類・確認日を表示します。価格・内容・販売状況・日持ちは購入前にリンク先で確認してください。日持ちの起算日は出典により異なります。

データ更新は、管理者が元CSVを更新した後に以下を実行します。このアプリで品の追加・削除や値の訂正を行うことはありません。

```sh
npm run data
# 別の配置のCSVを指定する場合
python3 scripts/build_data.py /path/to/temiyage_master.csv
npm run typecheck
npm test
npm run build
```

生成した `src/data/items.json` も管理対象です。変換は数値の型変換、空の数値のnull化、タグの配列化、個包装・確認状況の真偽値化、保存方法の表示ラベル生成を行います。保存方法と日持ちは原文も保持します。元CSVは変更しません。

スコアは `src/lib/score.ts`、URL条件の検証・復元は `src/lib/url.ts` に分離しています。

テストはNode.js標準の `node:test` を使います（Node.js 18以上）。この作業環境ではnpmレジストリの名前解決ができずvitestを取得できなかったため、追加依存なしでスコアとURL復元を検証しています。テスト対象のTypeScriptは既存のTypeScriptで一時的に変換し、テスト後に削除します。
